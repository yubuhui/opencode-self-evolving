# 布局承载、滚动可达与动态交互

## 适用条件与风险

适用于文字被裁切、界面超高、固定容器、长列表、响应式布局、动态表单与弹窗。目标是验证内容可读、操作可达、结果正确，并识别布局与异步状态之间的耦合。

用例字段复用 [统一场景模板](../../test-scenario-design/references/scenario-design.md)。项目组件规范决定截断、滚动、焦点、动效和支持范围。

## 1. 建立场景坐标

记录内容、窗口尺寸、容器尺寸、浏览器缩放、字体、状态、输入方式。用常用场景作为基准，先单独改变风险维度，再组合已知会互相影响的因素。

| 维度 | 推导样本 | 主要断言 |
| --- | --- | --- |
| 文本长度 | 空/单字/短/临界/超长，多行和连续长串 | 显示策略正确，全文入口有效，相邻元素可用。 |
| 字形与编码 | 汉字/拉丁字母/数字/组合字符/emoji/项目支持的语言 | 按实际字形宽度判断布局，复制/展开得到完整内容。 |
| 条目与表单 | 0/1/多项，验证消息，展开详情 | 首尾内容、计数和操作可达，布局状态正确。 |
| 宽度与高度 | 常用、最小支持、断点两侧、低高度 | 布局按约定调整，关键内容保持可达。 |
| 缩放与字体 | 项目支持的缩放级别，字体加载后的布局 | 文本/控件可读可用，固定元素和滚动范围正确。 |
| 动态状态 | 加载→成功/空/错误，编辑→提交→失败/成功 | 状态提示出现后内容、焦点和操作仍正确。 |

取值来自项目支持矩阵。缺少支持范围时，先记录当前窗口和实际问题窗口作为探索样本，再确认正式验收范围。

## 2. 文本承载与截断

### 推导与执行

1. 确认限制是字符数、字节数还是视觉宽度；确定换行、省略、展开或详情入口的产品策略。
2. 若契约明确最多 8 个计数单位，测试 7/8/9，并核对计数规则；如果只是某字体下约放下 8 字，则用真实渲染探测容量临界，再改变窗口/字形/缩放。
3. 构造短文本、临界内容、超长连续串、多行及混排，检查邻近按钮、标签、表格列与整体宽度。
4. 对允许省略的内容，使用鼠标和支持的键盘方式打开全文路径，核对完整值；需要触屏支持时验证对应入口。

### 正确结果与证据

- 按契约完整显示，或清楚地提示省略并提供可用全文路径。
- 全文入口取得的内容与源数据一致，字形/换行/复制符合约定。
- 截断和换行保持关键操作可用；容器之外的横向溢出按产品契约判断。
- 保存原始测试文本、窗口/字体条件、展示和展开截图以及操作结果。

几何测量可对比滚动尺寸与可视尺寸以定位裁切，但允许省略、虚拟化等设计需要结合契约判断。浏览器原生悬停提示的出现本身不足以证明键盘或触屏可达。

## 3. 超高界面、滚动与遮挡

### 推导与执行

1. 确认滚动责任：页面、弹窗内容区、列表还是多层容器；确认固定头/底栏与背景锁定策略。
2. 构造刚好容纳和略超容纳的内容，再测试低高度、缩放、错误提示/展开区域增加高度。
3. 用实际滚轮、滚动条或支持的触摸方式到达顶部、底部和目标条目。记录真正移动的滚动容器。
4. 到达底部后实际操作关键按钮，核对事件命中和业务结果；用键盘导航到同一目标并执行。
5. 对固定头/底栏、浮层与嵌套容器检查覆盖区域、焦点露出和滚动后的可达性。

### 正确结果与证据

- 按约定能看到所有必需信息并操作关键控件，首尾内容得到验证。
- 目标滚动区能够工作；弹窗锁背景时背景保持锁定，滚动链按约定表现。
- 控件进入可视范围后可命中，焦点可见且能完成操作。
- 记录首尾/问题点截图、滚动与点击步骤、目标几何/遮挡信息及数据结果。

页面和弹窗的合法滚动条属于正常设计；多余滚动与布局跳动按项目容差和体验要求判断。虚拟列表到达后还需等待目标条目实际渲染。

## 4. 动态状态与键盘交互

从项目支持的状态中选择与本次改动相关的转换：

| 转换/操作 | 核验重点 |
| --- | --- |
| 加载结束后出现长内容 | 布局重新计算，滚动范围和当前对象正确。 |
| 校验错误/网络错误出现 | 提示可读且能定位，输入与底部操作保持可达。 |
| 提交中关闭或切换 | UI 状态与返回后的数据一致，响应归属正确。 |
| 展开/折叠长区域 | 内容与焦点保持合理，键盘能继续导航。 |
| 删除当前选中项 | 选中态、详情、计数和焦点去向符合契约。 |
| 打开/关闭弹窗 | 初始焦点、Tab 顺序、关闭方式、返回焦点符合组件语义。 |

相同语义角色使用一致操作；编辑区聚焦与展开触发器切换可采用不同动作。快捷键、Esc 和焦点约束按组件契约验证。

异步等待使用可观察状态和超时。若快切换、连点涉及竞态或重复副作用，转入 [状态与一致性](../../test-scenario-design/references/state-consistency.md) 验证，并保留 UI 操作证据。

## 5. 高风险组合

优先验证共享同一空间、焦点或状态的组合：

- 长内容＋最小支持窗口：全文路径、相邻操作与横向承载。
- 低高度＋错误提示＋固定底栏：最后一项、错误信息、保存按钮均可达。
- 缩放＋展开详情：滚动范围、焦点和关闭入口。
- 加载中切换＋迟到响应：数据归属、加载提示和操作状态。

其他组合按风险取样，记录取样范围。简单文案改动可复用代表尺寸和长内容检查；已知耦合风险采用有针对性的组合。

## 6. 两个验收示例

### 例 A：标题容器展示不全

示例契约：允许单行省略，提供可用的全文展开入口。

测试短/临界/长标题以及混排、窄窗口组合。逐个检查省略反馈、展开全文与源值一致、关闭后焦点合理、相邻按钮可点击。若项目要求标题全部显示，则以完整展示为预期并调整用例。

### 例 B：弹窗内容超过窗口

示例契约：背景锁定，弹窗内容区滚动，底部保存动作始终可达。

在常用及最小支持窗口下，加载超高内容，增加校验错误，再按支持范围缩放。滚至末项，用鼠标和键盘分别到达并执行保存，核对存储结果；关闭弹窗后核对焦点和背景滚动恢复。

以上示例提供推导方法；实际场景的尺寸、数据、入口和结果应来自项目并记录执行证据。

## 7. 完成判定

每项已选高风险场景都有实际渲染、操作及预期结果证据。静态检查、截图、几何测量与业务断言各记录其覆盖边界。缺少运行环境时保留场景和可执行步骤，向总控报告阻塞与未验证项。

## 红线兜底

- 截断按产品契约及全文可达性判定；不得仅凭元素尺寸或省略号出现宣告信息完整。
- 滚动到底后实际执行目标动作并核对结果；不得把 DOM 存在或自动滚入视图等同于用户可操作。
- 窗口、字形和缩放分别记录；不得假设 emoji 或汉字始终占固定字符宽度。
